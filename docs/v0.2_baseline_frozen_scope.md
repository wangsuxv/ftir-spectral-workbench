# v0.2.0 baseline-frozen scope

状态：已通过本地发布验收并上传公开 GitHub 功能分支，尚未合并默认分支、打 tag 或正式发布。

## 目标

v0.2.0 以冻结的 v0.1.0 baseline 科学路径为起点，只交付四类增量：

1. Coarse/Fine Preview；
2. Series Consistency & QC；
3. A↔T 显示与独立派生导出；
4. Cross 2 与完整 Self/Cross block overview。

## Baseline Freeze

以下路径不得因 v0.2 改变：

```text
src/ftir_baseline/**
tests/baseline_regression/**
legacy/baseline_streamlit_app.py
```

`artifacts/v0.1_baseline_freeze_manifest.json` 保存起始 SHA-256。发布前必须重新计算并逐项比较，并确认：

```bash
git diff --exit-code <v0.1-start-commit> -- \
  src/ftir_baseline \
  tests/baseline_regression \
  legacy/baseline_streamlit_app.py
```

对同一输入和配置，`absorbance_full`、`absorbance_selected`、`baseline_estimation_spectra`、coarse/fine/total baseline、`analysis_data`、normalization、Prepared arrays/hashes、self/stored-cross matrices 和 peak-order evidence 必须与 v0.1 逐元素一致。

## Draft / Preview / Adopt

Coarse 和 Fine 控件先生成临时 validated draft。Preview 对完整原始序列调用冻结的 pipeline；选择代表谱只影响展示。

| 操作 | committed baseline config | 正式 baseline result | Prepared / 2D |
|---|---:|---:|---:|
| 修改 draft 控件 | keep | keep | keep |
| Preview / 切换代表谱 | keep | keep | keep |
| 查看 Candidate Gallery | keep | keep | keep |
| Adopt / Apply 不同配置 | update | invalidate | invalidate |

Preview result 保存在独立 session key，不得作为 baseline export 数据。Candidate Gallery 可比较 Endpoint linear、Anchor PCHIP、arPLS、AsLS、airPLS 和 Rubberband，但不会自动采用 rank 1；启发式排序不是真实物理基线的证明。

## Series Consistency & QC

该页面只消费正式 `PipelineResult` / `QCResult`：

- Raw absorbance、Coarse、Fine、Total、Corrected 五张热图；
- 全部 `QCResult.per_spectrum` 字段及对齐的 perturbation label；
- baseline continuity、residual diagnostics、peak preservation 三组趋势；
- 实际 spectrum index / label 的单谱 drill-down；
- 显示筛选与 CSV 下载。

页面不得重新实现 QC、自动删除或重排谱、clip negative corrected absorbance，或修改 result 数组。显示色阶不属于科学数据。

## A↔T 显示与派生导出

原有 `%T/T → A` 科学入口保持不变。新增反向仅为显示/派生表示：

```text
T = 10 ** (-A)
%T = 100 * 10 ** (-A)
```

- 输入复制为有限 float64；complex、NaN、Inf 和 overflow 明确失败；
- identity absorbance 返回 owned copy；
- 不裁剪，负 A 可以产生 `%T>100`；
- 唯一派生数据源是 `PipelineResult.analysis_data`；
- CSV 明确标注“baseline-corrected absorbance 的数学表示，并非仪器原始透过率”；
- 两份 CSV 独立下载，不进入 baseline ZIP；
- 显示单位变化不修改 baseline config、Prepared、2D 或任何 fingerprint。

## Cross 2

计算数量保持：

```text
unique cross pair count = C(n, 2)
oriented cross map count = n(n - 1)
```

每个 `CrossRangeResult` 暴露：

```text
Phi_reverse = Phi_stored.T
Psi_reverse = -Psi_stored.T
```

`row_variable` / `column_variable` 决定真实 row/column range：`nu1` 对应 first range，`nu2` 对应 second range；不能把 stored rows 固定解释为 first range。Cross 1/Cross 2 是矩阵 orientation，不是因果方向。

完整 N×N overview 的对角线使用 self matrices，非对角线分别使用 stored 或 reverse view。它不重新调用 2D 核心。Cross 2 不增加 `CrossRangeResult`、不改变 fingerprint，也不重复 peak-order evidence。

v0.2 2D bundle 保留 v0.1 stored 文件，并增加 reverse synchronous/asynchronous CSV 与 `orientations.json`。新版 verifier 验证 identity、轴、variable/range metadata 和计数；没有 additive reverse contract 的完整 v0.1 bundle 仍兼容。

## 明确排除

本版本不实施：

- 多个独立 Baseline Blocks；
- 全局基线后的局部 range correction；
- processing range / analysis range 双范围模型；
- `AnalysisRangePreparationService`；
- global-only / local-fine 双分支；
- baseline sensitivity Run A/B/C；
- 新基线方法或方法参数语义变化；
- baseline config schema、workflow state 或 baseline bundle 变化；
- 独立区间端点强制归零；
- PySide6/macOS `.app`；
- 大规模 Streamlit 架构重写。

## 隐私与发布

公开源码与文档不包含实验原始谱、私有派生 ZIP/`.ftirw`、数据维度、数据 fingerprint 或产物 hash。`data/original/` 仅是被 Git 忽略的本机入口。当前 v0.2.0 候选已上传公开功能分支；默认分支合并、tag 与正式 release 尚未执行。
