# Baseline methods

本文记录 FTIR Baseline Workbench 中每种方法的实现边界。所有方法都接收相同的 float64
`(n_spectra, n_points)` 数据合同；序列中不会逐谱改变算法、参数或锚点位置。

## 粗基线

### None / offset / linear

- `none` 返回显式零基线；适合确认无需粗调或只测试细调。
- `offset` 默认使用每谱最小值，也支持中位数、均值、分位数或显式常数。
- `linear` 用数值中心化后的一次最小二乘趋势。若吸收峰占据大部分范围，它可能受峰控制。

### arPLS / AsLS / airPLS / pspline-arPLS

这些方法是 `pybaselines` 的薄适配层，没有复制第三方核心算法。适配器负责：

- 升序内部拟合、按输入方向恢复；
- 整组锁定相同参数；
- 捕获警告和收敛历史；
- 记录 `lambda`、`p`、`tol`、`max_iter` 及拟合 metadata；
- 依赖缺失时抛出带安装建议的明确错误，不静默换算法。

`lambda` 与点数、采样间隔和波数范围相关，不能跨数据集机械复用。极宽 O–H/N–H 带尤其容易
被当作背景，因此候选画廊必须和峰保真度、锚点及时间一致性一起使用。

### Rubberband

实现为升序波数上的下凸包线性插值。适合窄峰和清晰下包络；凹形背景、噪声以及宽峰会使结果
不可靠。必要时可以只对估计通道轻微平滑，但最终校正仍从原谱扣除基线。

## 固定窗口细基线

### Endpoint-window linear

在选区两个边界附近各取固定宽度窗口，计算中位数或均值，再连接窗口代表点。窗口被选区边界
截断；实际代表波数由同一批窗口样本计算，因此不规则网格上的纯线性谱也能精确恢复。

### Strict endpoint

直接连接最靠近两端的两个数据点，端点严格归零。它对端点噪声和端点处真实吸收高度敏感，
只在高级选项中提供，并始终产生警告。

### Multipoint linear / PCHIP / polynomial

每个固定窗口为每条谱计算一个代表强度，窗口中心作为固定横坐标。要求：

- 至少两个启用窗口；
- 窗口按严格升序或降序给出，不得重叠或接触；
- 代表坐标覆盖整个选区，不做静默外推；
- 两个 PCHIP 锚点自动退化为直线；
- 多项式仅允许 1–3 阶，并要求足够锚点。

高阶多项式未提供，因为在锚点之间振荡和吞宽峰的风险太高。

## 粗调与细调组合

组合始终显式保存：

```text
B_total = B_coarse + B_fine
A_corrected = A_raw_absorbance - B_total
```

`compose_baselines()` 验证形状和有限性，并记录浮点重建误差。开启平滑时，粗、细基线在平滑
估计通道上确定，但上式中的 `A_raw_absorbance` 始终是未平滑选区谱。

`shared_shape` 是特殊序列分解：公共弯曲形状保存为粗分量，每谱常数和斜率调整保存为细分量；
不会再重复施加第二次锚点校正。

## 方法选择提示

- 单个窄区间且端点无吸收：endpoint-window；
- 已知多个无吸收窗口：PCHIP 或 multipoint linear；
- 未知峰位置、缓慢弯曲背景：先比较 arPLS / AsLS / airPLS；
- 清晰凸下包络和窄峰：可比较 rubberband；
- 相似基线形状但随时间偏移/倾斜：shared-shape；
- 低信噪比的相关序列：collaborative PLS，但仍需检查宽峰和收敛。

任何候选分数都只是排序工具。最终决定需要光谱化学知识、无吸收区证据和对关键峰区的检查。
