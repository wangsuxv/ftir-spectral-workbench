# 普通光谱独立批量处理：纯合成示例

本目录全部数据由 `generate.py` 的确定性公式生成，**不是实验数据**。名称只是展示标签；各谱之间没有时间、温度或其他实验扰动关系。合成参数用于验证导入和状态流程，不代表真实样品的推荐基线配方。

| 文件 | 导入单位 | 独立条目 | 波数轴 / cm⁻¹ | 点数 |
|---|---|---:|---|---:|
| `synthetic_wide_A.csv` | A / absorbance | 3：M1、M2、PHEMA | 4000 → 800，降序 | 每谱 401 |
| `synthetic_percent_T.csv` | %T / percent_transmittance | 1 | 900 → 3800，升序 | 291 |
| `synthetic_fraction_T.csv` | T / fraction_transmittance | 1 | 3600 → 700，降序 | 581 |

在统一 Streamlit 界面中先选择“普通光谱模式”，一起上传三个 CSV，并为每个文件明确选择表中单位。导入应得到五个独立条目，保留三种实际坐标轴。前三条完整域结果可提供同轴宽表；五条一起导出应使用每谱 CSV ZIP，不能自动生成对齐宽表。

任选一条计算粗调预览并确认，再处理下一条；在粗调页下载已确认结果。完成所需细调预览和确认，或点击“确认不做细调”，然后在批量页导出最终结果。批量页还可以保存工作区 ZIP，并通过独立的恢复入口重载。详细步骤与状态规则见 [普通模式使用说明](../../docs/independent_batch_baseline.md)。

从仓库根目录重新生成同名合成文件：

```bash
python examples/independent_batch/generate.py
```

也可用 `--output-dir outputs/synthetic-independent` 生成到本机输出目录。生成器不读取外部数据，不使用随机数。人工吸光度函数为：

```text
A(x,k) = 0.12 + 0.00002 (x−800)
       + (0.3 + 0.08 k) exp(−((x−1700−35k)/95)²)
       + 0.08 exp(−((x−2900)/150)²)
       + 0.002 sin(x/13 + k)
```

宽表使用 `k=0,1,2`；%T 使用其升序轴上的 `k=0`、`100 × 10^(−A)`；T 使用其降序轴上的 `k=1`、`10^(−A)`。CSV 保留 float64 的 17 位有效数字。
