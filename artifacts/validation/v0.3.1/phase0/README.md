## Exact-baseline synthetic compatibility fixtures

`scripts/generate_v031_legacy_fixtures.py` exports the exact baseline through
`git archive`, starts a worker with that snapshot's `src` on `PYTHONPATH`, and
verifies the source locations of the imported packages. It uses seed 3100,
analytic synthetic peaks, and deterministic identities; it reads no experimental
data. Binary files remain only under ignored
`outputs/validation-private/v031/legacy/`:

- `legacy_workspace_v030.zip`: schema 1.0, same-name sources, mixed axes/units,
  confirmed coarse/fine, explicit fine skip, undecided fine, stale fine, and
  independent uncommitted drafts.
- `legacy_coarse_export_v030.zip`: four confirmed coarse spectra on their own axes.
- `legacy_fine_export_v030.zip`: two ready final spectra, with excluded-item reports.
- `expected_arrays.npz`: raw axes/values and every saved baseline component.
- `legacy_generation.json`: actual source/version/identity/hash metadata.

The first generator attempt rejected the macOS temporary-directory alias before
extracting files; its failure log is retained. Canonicalizing the temporary root
fixed the utility's path check. The successful execution is
`legacy-fixture-generation.002.log`. A second, separately extracted exact Git
archive generated byte-identical ZIPs, NPZ, and metadata
(`legacy-regeneration.log`, `legacy_regeneration_comparison.json`).

To regenerate later without overwriting the original fixtures:

```bash
.venv/bin/python scripts/generate_v031_legacy_fixtures.py \
  --base-commit 9fc13c10ae34bd53cb220d0807edb18c9e2e41dc \
  --output outputs/validation-private/v031/legacy/final-regeneration
```

This directory records the starting baseline only. It does not claim that any
new v0.3.1 postprocessing acceptance scenario has passed.
